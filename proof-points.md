# Eventnexus Proof Points

This document defines proof points that can support the first public Eventnexus website.

## Purpose

The website should show that Eventnexus is not only a concept. It should point to real project experience: web platforms, AI-assisted tools, automation, service systems, and product experiments.

Proof points should be used honestly. If a project is public on GitHub but not polished as a public case study yet, describe it as a portfolio candidate or technical example rather than a finished client case study.

## Primary Proof Point

### Rootwise

- Website/example: `rootwise.site`
- Repository: `https://github.com/pikkst/rootwise`
- Related repository: `https://github.com/pikkst/rootwisePRO`
- Primary language: TypeScript

Rootwise should be treated as the strongest initial proof point because it is already named as a real example of work connected to the Eventnexus creator.

Recommended public positioning:

Rootwise demonstrates experience building a real web-platform product with modern frontend architecture and product-oriented thinking.

Before publishing a detailed case study, verify:

- current public site status
- core features that should be mentioned
- screenshots or demo flow
- whether `rootwise` or `rootwisePRO` should be the main reference

## Proof Point Categories For The Website

The first website can group proof points by capability instead of listing every repo.

Recommended categories:

- Web platforms and SaaS-style products
- AI-assisted business tools
- Data and dashboard experiments
- Marketing and lead workflow automation
- Media and content workflow tools
- Event, map, or mobile-adjacent platform concepts

## Public Website Guidance

For the first version, use concise proof language:

- "Experience building TypeScript-based web platforms and AI-assisted tools."
- "Previous work includes Rootwise and several AI/business workflow prototypes."
- "Eventnexus combines frontend, backend, automation, and deployment thinking into one delivery process."

Avoid claiming that every repository is a finished commercial product unless it has been reviewed and confirmed.
